### What I build

I ship production AI systems that solve real operational problems, then put them in front of users fast.

**Offline coding agent.** Claude Code running fully on a local open-weight model: a lean toolset, context compaction without a model call, and a guard that lets the agent run unattended without touching anything irreversible outside the project.
`Claude Code` `Ollama` `MCP` `Python`

**Voice remote for coding agents.** An iOS app that turns Ray-Ban Meta glasses into a hands-free remote: double-tap, speak, and Claude Code runs the request on the Mac and answers through the glasses speakers.
`Swift` `SwiftUI` `SSH` `Speech`

**Agentic video editor.** A Claude Code skill that turns raw rushes and a brief into a finished CapCut timeline: cuts, speed ramps, color grading, green screen, local subtitles, music ducked under the voice.
`Claude Code skills` `Python` `CapCut` `Whisper`

**Swiss law citation graph.** An offline-first mobile app that links Swiss law into one navigable graph: federal law, Federal Supreme Court case law and cantonal legislation in French, German and Italian. Every cross-reference resolves to the article it cites. Built agent-first with Claude Code, 600+ commits, in closed beta.
`Go` `PostgreSQL / pgvector` `React Native` `Expo`

**Spec-to-MVP pipeline.** Turns a raw client call into a structured specification and a working scaffold, compressing the gap between conversation and first running prototype.
`Python` `LLM tool-calling`

**Multi-market trading bot.** A data-driven prediction engine for prediction markets: market discovery, edge detection, execution, and live position monitoring from one CLI.
`Python` `NumPy / SciPy` `web3`

Most of this work is client or proprietary, so the repositories stay private. Happy to walk through any of it on a call, or grant repo access on request.
